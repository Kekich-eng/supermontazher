# B-roll и метафоры, цвет, монтажные программы

## B-roll и визуальные метафоры

Для каждой мысли сценария, где нет своего материала, подбираю картинку по порядку:
1. **Свой материал**: запись экрана, кадры игры, скриншоты, съёмка телефона — честнее всего.
2. **Анимация кодом** (Remotion): схемы, интерфейсы, счётчики, метафоры — дешёво и в стиле канала.
3. **Генерация**: ChatGPT (картинки), Kling (5-секундные ролики), Suno (музыка) — промпт пишу я, генерирует автор.
4. **Сток**: Pexels, Pixabay, Mixkit (видео) — бесплатно для коммерции, без указания автора. Запросы даю на английском, 2–3 варианта: `hacker typing dark room`, `server room lights`, `person reading phone night`. Скачивание — с согласия автора.

Метафоры для тем канала (проверенные и кандидаты):
| Мысль | Метафора |
|---|---|
| ИИ-агент из частей | робот собирается из деталей (`Agent`) |
| утечка данных | водопад карточек из бота (`BotShort` S1) |
| нейросети соревнуются | файтинг, табло счёта (`Boj`, `Sravn`) |
| ошибки в работе | монстры, здоровье проекта (`OshShort`) |
| MCP = руки нейросети | робот тянется к плиткам сервисов (`McpVideo`) |
| контекст переполнен | стакан/шкала переливается через край |
| экономия токенов | гора текста сжимается в три карточки |
| блокировка | падающая плашка, штамп, замок |

Промпт для Kling: что происходит + камера + свет + стиль, 5 с, одно действие: `The armored fighter raises a glowing turquoise shield, slow push-in camera, dark arena with rim light, cinematic, 5 seconds`. К промпту — исходная картинка из ChatGPT, чтобы персонаж не менялся.

В плане по секундам у каждой метафоры колонка «Ресурс» (`director.md`).

## Цвет

Анимация Remotion уже в палитре канала, цвет правится в основном у живых кадров (веб-камера, телефон, запись экрана).

- **Веб-камера автора** была мягкой и тёплой. Мягкая коррекция ffmpeg:
  `-vf "eq=contrast=1.06:saturation=1.08:gamma=0.98,unsharp=5:5:0.6"`. Кожу не уводить в оранжевый и зелёный: насыщенность не выше 1.12.
- **Единый стиль** с тёмным фоном: лёгкое затемнение краёв (виньетка в Remotion поверх видео) вместо затемнения всего кадра. Картинки автора сильно не затемнять.
- **Запись экрана**: не трогать цвет, только резкость при масштабировании (`OffthreadVideo` + `scale` без размытия; исходник 1080p не растягивать больше 1,3×).
- **Kling/ChatGPT** кадры подгоняй CSS-фильтром в Remotion: `filter: 'saturate(1.1) contrast(1.05)'`, при необходимости тёплый или холодный оверлей `mixBlendMode: 'soft-light'` цветом сцены.
- LUT: `-vf lut3d=file.cube` в ffmpeg, если автор пришлёт свой.
- Проверка: кадр до/после рядом в одном листе, показать автору.

## Монтажные программы

Основной путь канала — код (Remotion + ffmpeg): воспроизводимо, правки по таймкодам, я делаю сам. Если автор хочет сделать что-то руками или спрашивает «как это сделать в …», даю пошаговую инструкцию под программу, с названиями меню на русском интерфейсе, если он есть:

| Что | CapCut (ПК) | DaVinci Resolve | Premiere Pro / After Effects |
|---|---|---|---|
| Вырезать паузы | «Удалить паузы» / Smart cut в меню звука | Edit, клавиша B (лезвие), Ripple Delete | Text-based editing: удалить паузы из расшифровки |
| Субтитры | «Текст → Автосубтитры» | Fairlight/Subtitles → Create from audio (Studio) | Captions → Transcribe → Create captions |
| Пружинное появление | анимация «Отскок» на клипе | Fusion: ключи масштаба + Spline с перелётом | AE: ключи Scale + Graph Editor, выражение overshoot |
| Наезд камеры | ключи «Масштаб» | Inspector → Zoom, ключи | Effect Controls → Scale, ключи |
| Тряска | эффект «Тряска» | Fusion: Camera Shake | AE: wiggle(10,15) на позиции |
| Цвет | «Настроить → Цвет» | вкладка Color: Lift/Gamma/Gain | Lumetri Color |
| Экспорт для YouTube | 1080p, 30 к/с, высокий битрейт | H.264, 1080p, 20–40 Мбит/с | H.264, «YouTube 1080p» пресет |

Если инструкция по версии программы может отличаться — так и пишу, проверить по интерфейсу у него я не могу.
