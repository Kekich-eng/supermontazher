# Работа с Codex

Автор платит за подписку Codex и 18.10.2026 сказал: «вдруг тебе поможет, и вы как-то сможете соединиться и работать вместе, но я хочу, чтобы **за визуал отвечал ты**».

## Распределение ролей

| Codex можно | Codex нельзя |
|---|---|
| сверить список вырезов с расшифровкой (нет ли обрезанных слов, пропущенных дублей) | придумывать стиль, концепцию, раскладку сцен |
| ревью кода композиции: рассинхроны, наложения, сцены за пределами длительности | решать, как выглядит кадр, выбирать цвета и шрифты |
| починить сломанный рендер, ошибку TypeScript | менять одобренный автором стиль |
| проверить цифры и факты в сценарии/описании | писать финальные тексты для публикации без моей вычитки |
| механическая работа: перенос таймкодов, генерация карт кусков | |

17.10 Codex предложил концепцию оформления (светлый минимализм), автору она не понравилась. Отсюда правило: **визуальные решения только мои**, советы Codex по визуалу — на моё усмотрение, не к исполнению.

## Как вызывать

- Через агента `codex:codex-rescue` (Agent tool, `subagent_type: "codex:codex-rescue"`), для нового разговора `--fresh`. Около 3 минут на проверку. Расходует лимиты ChatGPT автора — зови по делу, а не на каждую мелочь.
- `/codex:review` требует git: в папке ролика `git init` и `.gitignore` с `*.mp4 *.wav *.mkv raw/ node_modules/`. Общий remotion-проект не git — для ревью кода композиции передай Codex путь к файлу и описание задачи через rescue.
- Codex не видит видео и не слышит звук, как и я: давай ему расшифровку, `map.json`, код и список времён.

## Когда звать по умолчанию

- Длинный ролик (> 3 мин) перед полным рендером: ревью кода композиции на рассинхрон (на шортсе про агента он нашёл 7 реальных ошибок, которые я пропустил по кадрам).
- Сложный черновой монтаж с многими дублями: вторая сверка `REMOVE` с расшифровкой.
- Рендер падает и я не нашёл причину за 2 попытки.

В отчёте автору пиши, что проверил Codex и что он нашёл. Его выводы перед применением проверяй сам.
