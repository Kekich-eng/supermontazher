# Библиотека звуков

Все звуки синтезированы кодом (`scripts/gen_sfx_pack.py`), прав третьих лиц нет, их можно распространять вместе с плагином.
Лежат в `public/sfx/`. Вызов: `<Sfx name="hit_sub" at={ev.boom} vol={0.4} />` (`kit.tsx`). Шесть базовых (pop, whoosh, ding, tick, swap, alert) делает `gen_sfx.py`.
Пересобрать в новом проекте: из папки remotion `python <навык>/scripts/gen_sfx_pack.py`. Файл даёт те же звуки при каждом запуске.

Подбираю по каталогу, но на слух звуки оценивает только автор. Я проверяю лишь цифры: длину, пики, спектр.

## Удары

| Звук | Когда |
|---|---|
| `hit_sub` | глубокий кинематографичный удар: главные моменты |
| `hit_hard` | жёсткий удар с треском: штамп, вылет заголовка |
| `hit_metal` | металлический удар со звоном: щелчок замка, важная цифра |
| `hit_soft` | мягкий глухой толчок: приземление карточки |
| `hit_snare` | сухой щелчок-малый барабан: ритмичные появления |
| `stamp` | штамп по бумаге: «ТАК СЕБЕ», «БЕСПЛАТНО» |
| `chord_hit` | тёплый аккорд-удар: открытие, вдохновляющий момент |

## Вжухи

| Звук | Когда |
|---|---|
| `whoosh_fast` | короткий резкий: быстрая смена сцены |
| `whoosh_mid` | средний: вылет окна |
| `whoosh_long` | длинный пролёт камеры |
| `whoosh_deep` | низкий тяжёлый: крупный объект пролетает мимо |
| `swish` | тонкий воздушный взмах: линии, нити, подписи |
| `swish_pan` | взмах слева направо: шторка |
| `whoosh_in` | нарастающий вжух, обрывается на ударе: вход перед ударом |

## Подъёмы

| Звук | Когда |
|---|---|
| `riser_short` | подъём 1,5 с: перед ударом |
| `riser_long` | подъём 3,5 с: разгон к кульминации |
| `reverse_hit` | обратный удар: втягивание в следующую сцену |
| `downlifter` | спад 1,5 с: после удара, сцена гаснет |
| `sub_drop` | падение баса: провал перед кульминацией |
| `tape_stop` | торможение плёнки: «стоп», всё останавливается |
| `drone_low` | низкий гул 4 с: тишина перед главным |

## Интерфейс

| Звук | Когда |
|---|---|
| `click_soft` | мягкий клик: кнопка |
| `click_hard` | твёрдый клик мышью: курсор нажал |
| `toggle` | переключатель: включилось |
| `hover` | лёгкое наведение: подсветка строки |
| `key` | одна клавиша |
| `typing` | печать 1,4 с: команда в терминале |
| `enter` | Enter: команда запущена |
| `notify` | уведомление: два мягких тона |
| `success` | успех: восходящая фраза, галочка |
| `error` | ошибка: глухой отказ |
| `counter` | счётчик набегает и ускоряется 1,5 с |

| Звук | Когда |

## Скачанные библиотеки (по желанию)

Записанные звуки в плагин не входят: они занимают место, а часть лицензий запрещает раздавать файлы отдельно. Скачай их сам в `video/sfx-library/` и собери каталог `scripts/sfx_index.py <sfx-library> <public/sfx/lib>`: появятся `catalog.md`, `index.json` и ссылки в `public/sfx/lib/`. Вызов: `<SfxFile file="lib/k_impact-sounds_x.ogg" at={ev.boom} vol={0.3} />`.

- Kenney (kenney.nl): CC0, подходит и для роликов, и для распространения.
- Mixkit (mixkit.co): бесплатные кинематографичные вжухи и удары. Прочитай их лицензию сам перед использованием.

У скачанных звуков разная тишина в начале и разная громкость: замерь у каждого пик и начало звука и ставь его по этим цифрам, иначе звук опаздывает.

## Рецепты

- Главный удар: `riser_short` заранее (конец подъёма на ударе) + `hit_sub` + `Shake` + `Flash`.
- Кульминация: `drone_low` в тишине, `sub_drop` перед событием, затем серия `lock_in` и `hit_metal` на последнем.
- Вылет окна: `whoosh_mid` + `hit_soft` на приземлении. Счётчик: `counter`, в конце `ding` или `success`.
- Команда: `typing`, `enter`, потом `data`. Ошибка: `glitch_short` + `error`.
- Волшебное появление: `shimmer` + `chord_hit`. Улучшение: `sparkle_up`.
- Не больше одного заметного звука в 0,3 с. Громкость начинай с 0.15–0.25, удары и подъёмы до 0.4.
