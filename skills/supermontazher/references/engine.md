# Монтажный движок: сцены на словах, а не на секундах

С 26.10 (шортс «Самая крутая анимация»). Зачем: раньше все времена в композиции были секундами ролика. Вырезали
запинку — сдвигалось всё после неё, и 40 чисел пересчитывались руками. Теперь в композиции секунд раскладки нет:
каждая сцена, удар и окно громкости привязаны к слову озвучки, а секунды считает скрипт.

## Как устроено

```
video/<ролик>/edit.json       ЯКОРЯ: сцены, события, куски записей, паузы, музыка, окна громкости (правим руками)
video/<ролик>/make.py         одна команда (обёртка над scripts/montage.py)
video/<ролик>/edit_resolved.md  таблица: время -> сцена -> якорь -> какое слово нашлось (читать после сборки)
remotion/src/<имя>Edit.json   ВЫЧИСЛЕНО: секунды для Remotion (руками не править)
remotion/src/<имя>Words.json  слова во времени ролика (субтитры)
```

`python make.py` делает подряд: `talk/build_voice.py` (REMOVE) → `voice.py` → `verify.py` (Whisper, кэш по хэшу
звука в `talk/.words_cache/`: без правок голоса — 2 секунды, с правками — около 30 с) → паузы под картинку →
`voice_video.wav` → музыка под итоговую длину → слова → раскладка. Файлы в `public/<имя>/` — жёсткие ссылки на
`voice_video.wav` и `music_video.wav`, скрипт пишет в тот же файл и проверяет ссылки.
Режимы:

| Команда | Что | Время на шортсе 1:24 |
|---|---|---|
| `python make.py --build` | только сборка | 2 с (с новой расшифровкой ~30 с) |
| `python make.py --audio` | сборка + звук ролика `review/audio_mix.wav` (композиция `<Имя>Audio`, записи не декодируются) | ~30 с |
| `python make.py` | сборка + черновик `review/draft.mp4` 540×960/30, копия `draft_phone.mp4` < 30 МБ, лист `draft_sheet.jpg` (начало каждой сцены + 0,6 с) | ~3,5 мин |
| `python make.py --full` | сборка + финал в `render.out`; если файл уже есть, пишет «(новый).mp4» рядом, `--force` перезапишет | ~13 мин, в фоне |
| `python make.py --animatic` | сборка + аниматик `review/animatic.mp4` (+ телефон, лист): готовые сцены как есть, остальные заглушками | ~1,3 мин |
| `python make.py --scene s3` | сборка + лист одной сцены `review/scene_s3.jpg`: 9 кадров финала от начала до конца, под кадром события, которые сработали (`--scene s3,s4` — несколько) | ~1 мин |
| `--no-voice` | не пересобирать голос (правил только якоря) | |

Каждая сборка дописывает итог в блок «Последняя сборка» в `STATE.md` ролика.

## Якоря (подробно — в шапке scripts/montage.py)

| Запись | Что значит |
|---|---|
| `"Раунд первый"` | начало первого слова фразы (без регистра, «ё»=«е», без знаков, «HTML-страница» = одно слово) |
| `"она *взрывается"` | звёздочка — нужное слово, остальные только чтобы найти место |
| `"она взрывается]"` | конец слова (без звёздочки — конец последнего) |
| `"Раунд первый -0.09"` | сдвиг в секундах |
| `"Одно задание#2"` | второе вхождение (лучше удлинить фразу) |
| `"@s2"`, `"@s2.end"`, `"@boom +0.18"`, `"@pause3"`, `"@T"` | ссылки на сцены, события, паузы, конец ролика |
| число | секунды: в `ev` — от начала сцены, в `at` и окнах — от начала ролика |

Фраза ищется по всей озвучке. Нет дословно — берётся похожая с предупреждением (Whisper пишет «анимации» вместо
«анимация»). Встречается дважды — ошибка со списком мест. Пишите фразы по 2–3 слова, уникальные.

Сцены в `scenes` идут подряд, конец сцены = начало следующей. Поля, кроме `id/at/end/ev/pieces`, проходят в
композицию как есть (`kind`, `who`, `name`, `hudTop`…). Куски записи `pieces`: `{from, to?, rate?, until?}` —
скорость подбирается сама (`from`+`to`+`until`), или считается конец (`from`+`until`), последний кусок тянется до
конца сцены. Паузы: `{"after": "она взрывается", "dur": 1.0}` — тишина посередине промежутка после фразы.
Музыка: трек `from`→`join`, затем повтор `bars` тактов до конца файла; берётся самый короткий вариант, который
закрывает голос + `min_tail`, длина ролика = длина музыки.

В композиции: `import EDIT from './<имя>Edit.json'`, `S = EDIT.scenes`, `S.hook.ev.boom` — секунды от начала
сцены, `<Seq at={S[id].at} dur={S[id].dur}>`, `EDIT.windows.loud`, длина `EDIT.T`. Числа, которые остаются в
.tsx, — только оформление и моменты внутри записей (секунды исходника: где в записи взрыв).

## Аниматик (идея из PresBuilder, 29.10)

Ролик можно смотреть целиком до того, как нарисована хоть одна сцена: `src/animatic.tsx` → компонент
`<Animatic edit words real>`. Сцена без готового компонента показывает заглушку: название (`title`), задачу (`note`)
из edit.json, события-чипы, которые вспыхивают в свою секунду, куски записей с текущей секундой исходника и
слова озвучки с подсветкой. Голос и музыка звучат по-настоящему. Готовые сцены передаются в `real={{hook: <Hook />}}`
и масштабируются сами (сделаны под 1080×1920).

Порядок для нового ролика: монтажный план → `edit.json` со сценами, `title` и `note` → `python make.py --animatic` →
Автор смотрит ритм и длины на телефоне (2 МБ) → рисую сцены по одной, добавляя их в `real`. Композиция
`<Имя>Animatic` 540×960, 30 к/с, имя в `render.animatic`. Образец: `AnimaciyaAnimatic` в `src/Animaciya.tsx`
(готов только хук). Копия компонента — `remotion-template/src/animatic.tsx`.

## Правка после замечаний автора

1. Таймкод запинки → `REMOVE` в `talk/build_voice.py` (секунды исходника, уточнить `win.py`).
2. `python make.py` → читать вывод: предупреждения, кандидаты verify, таблица сцен.
3. Лист кадров черновика (начала сцен) или `python make.py --scene s3` для сцены, где правили: субтитр в кадре совпадает со сценой, удары на своих словах.
4. Черновой рендер `AnimaciyaDraft` (540×960, 30 к/с) или сразу полный.

## Новый ролик (шаблон баттла)

Скопировать `templates/edit.json` и `templates/make.py`, поменять `name`, `public`, фразы якорей, `music`, `clips`.
Композицию собрать так же, как `src/Animaciya.tsx`: сцены `hook / rules / tape / r1 s1 s2 / r2 s3 s4 / r3 s5 s6 /
final / end`, плашки `kind: plate`, сцены записей `kind: shot`. Рядом две служебные композиции, их имена в `render`:
- `<Имя>Draft` — обёртка `scale(0.5)`, композиция 540×960, 30 к/с;
- `<Имя>Audio` — контекст `AudioOnly` (видео-вставки возвращают null), обёртка `display: none`, композиция 16×16
  **с тем же fps, что финал** (при 30 к/с звуки ударов сдвигаются на полкадра, звук не совпадает с финальным).

## Черновой рендер

`python make.py` (или вручную `npx remotion render src/index.ts AnimaciyaDraft ../../animaciya/review/draft.mp4`).
Только для проверок, не для публикации. Лист кадров черновика проверяет агент `montage-checker` (`agents.md`).

## Грабли

- Whisper при перерасшифровке может чуть сдвинуть слова (до 0,1 с) и поменять написание: смотреть предупреждения.
- Слово, которое кончается ровно в точке паузы, теперь кончается до паузы (раньше «тоннель» тянулся через паузу).
- Музыка: точка повтора по сетке тактов (`bpm`), если в `exact` не задана ручная (у animaciya `{"10": 36.64}`, подобрана на слух; без неё сдвиг 2,6 мс).
- Рендер `--codec=wav` полной композиции всё равно рисует все кадры (4,6 мин): звук только через `<Имя>Audio`.
