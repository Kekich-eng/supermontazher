# Запись экрана и вставки

## Запись

`scripts/record.ps1` пишет весь экран в `raw/` и останавливается, когда рядом появляется `stop.flag`. Запускай в фоне (`run_in_background`), останавливай созданием флага. Размер файла во время записи в списке папки не растёт, это нормально.

Кто что делает:
- **Сторонние установщики из интернета и ввод ключей — только руками автора.** Ты читаешь код установщика до запуска, объясняешь, что он меняет, и пишешь экран, пока он нажимает.
- Уже установленную программу запускать можно. Чистый дубль в видимом окне: `Start-Process` со скриптом-обёрткой, см. `examples/example_run_demo.ps1` (крупный шрифт консоли через `SetCurrentConsoleFontEx`, удаление переменных окружения сессии Claude, отдельная папка настроек).
- В окна терминала печатать нельзя: нажатия внутри окна делает автор или они передаются аргументами.
- Окном самого Claude управлять нельзя. Запись его настроек автор делает в OBS сам, ты размываешь чат и почту: размытый кадр целиком + резкие вставки на нужные области, включённые по времени.

## После записи

1. Обзорный лист: `python $SK\contact_sheet.py raw\<файл>.mkv review\raw_sheet.jpg 10`. Просмотри целиком: ключи, блокнот с паролями, чужие окна, уведомления мессенджеров, вкладки, панель задач.
2. Нарезка по образцу `examples/example_cut_clips.sh`: обрезка до нужного окна, размытие поля с ключом, 1920×1080. Ошибки и моменты, где автор путался, не включай без просьбы.
3. Проверь размытие кадрами в нескольких точках каждого куска.
4. Скажи автору, что в `raw/` остался исходник с видимым ключом.

Грабли: `boxblur` требует радиус меньше половины высоты области по цветности: для узких полос радиус до 14.

## Вставка в ролик

- Окно с тенью, подпись под окном, говорящий уезжает в угол — `examples/Full_face_screen.tsx`.
- Синхронизация со словами: разложи клип по кадрам каждые 5 с, найди моменты действий, раздели на отрезки со своим `playbackRate` (медленно, где объясняют; быстро, где установка), на ускоренных значок «×4» (`Chip`).
- Два источника рядом («Сравнение»): обрезать вкладки браузера и панель задач, 1600×822, оба 30 к/с.

## Другие источники картинки

- **Нарисованные окна** вместо записи («10 фишек»): окна Claude Code рисуются анимацией, текст печатается по буквам. Чище и читаемее записи, если действие простое. На экране не выдавать за запись.
- **Кадры своей игры** снимаются скриптом через браузер (Playwright/puppeteer): `video/igra/capture/cap_lab.js`, `cap_games.js`.
- **Скриншоты страниц**: встроенный браузер Remotion: `node_modules/.remotion/chrome-headless-shell/.../chrome-headless-shell.exe --window-size=1920,1080 --virtual-time-budget=8000 --screenshot=<файл> <адрес>`. Системный Edge в безголовом режиме файл не создаёт.
- **Съёмка телефона** (уведомление пришло) — настоящая, автор снимает сам.
- **ChatGPT-картинки и Kling-ролики** (персонажи, арена «Боя»): Автор генерирует по твоим промптам. Промпты пиши на английском, прикладывай референсы, требуй «use the attached characters exactly». Kling-ролики: 5 с, вставлять с влётом и медленным наездом (`Kl` в `examples/Boj_long_dark.tsx`).
- **Растущий граф Obsidian** — на отдельной демо-базе, `examples/example_obsidian_graph_grow.py`. Салатовые точки автору не нравятся: у каждого проекта свой цвет на тёмном фоне. В кадре подпись «демонстрация».
