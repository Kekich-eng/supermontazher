# Проверка и рендер

Я не слышу звук и не вижу движение: вижу кадры, текст расшифровки и цифры громкости. Поэтому проверка — по чек-листу, а не «на глаз».

## Перед рендером

1. `npx tsc --noEmit` в общем проекте.
2. Контрольные кадры: `python $SK\contact_sheet.py --remotion <Комп> review\sheet.jpg 0.6,5.2,... 4` из папки remotion — 15–20 точек: начало каждой сцены + 0,6 с (после влёта), середины сложных сцен, финал. Смотри лист целиком.
3. Чек-лист по листу:
   - нет пустых кадров и чёрных провалов между сценами;
   - текст не обрезан краем, не налезает на другой текст, читается на телефоне (≥ 40 px для подписей в 1080p);
   - в шортсе субтитры на 1470 и ничего важного у нижнего края;
   - обводки и стрелки попадают в цель, окна не пустые;
   - картинки автора не затемнены и не размыты сильно;
   - цифры на экране совпадают с речью и источниками.
4. Синхрон: выпиши 5–10 ключевых слов из `words_final.json` и проверь, что появления в коде стоят на их времени.

## Рендер

- Образец: `npx remotion render src/index.ts <Комп>Sample out\<имя>_sample.mp4 --crf=18`.
- Полный ролик — в фоне (`run_in_background`): 5 мин ролика ≈ 15–20 мин рендера при 30 к/с.
- Итог копируй/рендери сразу в `video/<ролик>/<Название>.mp4`.

## После рендера

1. `python $SK\contact_sheet.py "<ролик>.mp4" review\final_sheet.jpg 10` — финальный лист.
2. Звук: `ffmpeg -i "<ролик>.mp4" -af ebur128=peak=true -f null -` — голос около −16…−14 LUFS суммарно, пик не выше −1 дБ.
3. Повторная расшифровка готового звука при сомнениях в вырезах (`transcribe.py`): нет обрезанных слов на склейках.
4. Лёгкая копия: `powershell -ExecutionPolicy Bypass -File $SK\preview.ps1 "<ролик>.mp4"` → `preview.mp4` < 30 МБ, отправь через `SendUserFile`.

## Контроль качества перед выкладкой

| Что | Как проверить | Норма |
|---|---|---|
| Параметры файла | `ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,bit_rate -of compact "<ролик>.mp4"` | H.264 + AAC, 1920×1080 (шортс 1080×1920), 30 или 60 к/с, `+faststart` |
| Длина шортса | ffprobe duration | до 60 с (YouTube принимает до 3 мин, но удержание хуже), TikTok/Reels до 90 с |
| Громкость | `ebur128=peak=true` | около −14…−16 LUFS, пик ≤ −1 дБ |
| Субтитры | открыть srt глазами | имена и названия написаны верно, строки ≤ 40 знаков, нет «—», не съехали (сверить 3 точки с `words_final.json`) |
| Читаемость текста | лист кадров, уменьшенный до 480 px | текст читается на маленьком листе = читается на телефоне |
| Цвет | лист кадров | нет пересвета белых областей, лицо естественное |
| Личное | лист кадров raw и готового | ни одного ключа, пароля, почты, чужих сообщений |
| Права | список всех внешних материалов | музыка: Mixkit/Suno/incompetech со строкой автора; сток: Pexels/Pixabay/Mixkit; логотипы — только для обозначения продукта; чужие ролики — только короткими цитатами с источником |
| Обещания | список обещаний из `director.md` | всё обещанное в начале показано; обещанное «в Telegram» готово |
| Цифры | сверка с источниками | каждая цифра на экране имеет источник, непроверенные помечены автору |
