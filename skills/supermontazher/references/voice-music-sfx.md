# Голос, музыка, звуки

## Голос

Обработка по умолчанию — почти никакой: `scripts/voice.py` (highpass 70 Гц → постоянное усиление до −15,5 LUFS → только при пиках выше −1 дБ мягкий `alimiter ... level=disabled`). Так звучат одобренные «Бой», «Сравнение», «Агент» (−15,5 LUFS, пик −0,9…−1,5).

История, почему именно так:
- 05.10: цепочка шумодав + ускорение + подъём верхов + деэссер + сильный компрессор → «голос как у ИИ, с шумом и дисторшеном».
- 10.10: `alimiter` с авто-подъёмом громкости (по умолчанию `level=enabled`) дотягивал звук до максимума → «сильный дисторшн». Выбран вариант почти без обработки.
- В OBS у автора уже стоят шумоподавление и компрессор. Второе шумоподавление (`afftdn`) и `atempo` дают роботизированный призвук: не используй.
- Однопроходный `loudnorm` на голос не ставь.
- Сомневаешься — пришли два образца по 15 с (без обработки и с обработкой), автор выберет на слух.

## Музыка

Громкость под голосом: 0.08–0.10 (горизонтальные ролики без лица), до 0.15 для говорящей головы. Плавный вход 0.6–0.8 с и уход 1.4–2.2 с:
`<Audio loop src={...} volume={(f) => 0.09 * interpolate(f / fps, [0, 0.8, TOTAL - 2, TOTAL], [0, 1, 1, 0], clamp)} />`
В зрелищных сценах без голоса (бой, геймплей) музыку можно поднимать до 0.25–0.35 и прибирать обратно к голосу.

Источники, по порядку предпочтения:
1. **Mixkit** — современно, лицензия без строки об авторе. Прямой файл: `https://assets.mixkit.co/music/<номер>/<номер>.mp3`, номера ищи в коде страницы каталога (`curl` + поиск `assets.mixkit.co/music`). Выбранные автором: «Torey» (блокировка, шортсы), Pop Track 03 (Lily J, «10 фишек», и дальше как общий фон), Space Game (Francisco Alvear, аркадный шортс).
2. **Suno** — автор генерирует сам по твоему промпту (музыка «Боя»). Для фонка и треков с вокальными чопами: режим Instrumental, поле Lyrics пустое, вся фактура в Style of Music, иначе срабатывает фильтр авторских прав.
3. **incompetech** (Кевин Маклауд) — CC BY 4.0, в описание обязательна строка с автором. 06.10 автор отверг пять треков подряд как старомодные: предлагай в последнюю очередь.

Как выбирать: 2–3 кандидата по 20 с отдельными файлами (`video/<ролик>/music/`, `proby/`). Для длинного ролика подкладывай под один и тот же образец через ffmpeg, перерендер не нужен. Для шортса присылай отдельными файлами и не вставляй, пока автор не выбрал. Шортсу нужна музыка бодрее, чем длинному ролику.

## Звуки интерфейса

`scripts/gen_sfx.py` синтезирует свои звуки без чужих прав: `pop`, `whoosh`, `ding`, `tick`, `swap`, `alert`. В общем проекте они уже лежат в `public/sfx/`.

Большая библиотека ещё на 46 звуков (удары, вжухи, подъёмы, интерфейс, глитч, искры и вещи) делается `scripts/gen_sfx_pack.py`, каталог и рецепты: `references/sfx-library.md`. Перед саунд-дизайном открой каталог.

Правила саунд-дизайна:
- Звук попадает в кадр появления (тот же `at`), не раньше.
- Вжух (`whoosh`, 0.16) на каждой смене сцены — встроен в `Scene` из `kit.tsx`.
- Крупный заголовок → `pop` 0.2; мелкая подпись → `tick` 0.07; картинка/персонаж → `swap` 0.12; штамп/тревога → `alert` 0.3; итог/счёт → `ding` 0.2.
- Удар в шортсе = звук + тряска (`Shake hits`) + вспышка или искры одновременно.
- Не больше одного звука в 0,3 с, иначе каша. Звуки и музыку оценивает только автор: ты их не слышишь, скажи об этом.

## Финальный звук ролика

Remotion сводит голос, музыку и звуки сам. Пики суммы проверь замером после рендера:
`ffmpeg -i out.mp4 -af ebur128=peak=true -f null -` — пик выше −1 дБ → убавь музыку/звуки, а не ставь лимитер на всё.
