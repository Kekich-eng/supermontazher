# Упаковка к публикации

Ролик не готов, пока нет: файла с правильным именем, описания, субтитров, обложки (или промпта для неё), поста для Telegram. Делай всё это без отдельной просьбы, когда монтаж одобрен.

## Правила охватов автора (11.10.2026)

1. Имя файла ролика = название видео на YouTube (символы `: ? " / \ * < > |` убрать или заменить). Не «… - готовый ролик.mp4».
2. Название и превью отражают реальное содержание, без обещаний, которых в ролике нет.
3. Описание начинается с названия, второй строкой ссылка на этот же ролик (до публикации `[ВСТАВЬ ССЫЛКУ НА ЭТОТ РОЛИК]`).
4. Обложка должна цеплять — предлагай варианты.

**Без длинного тире «—» в любых публикуемых текстах** (описание, пост, закреп, титры): Автор считает его признаком нейросети. Ставь точку, запятую, двоеточие или обычный дефис. Тексты прогоняй через скилл «stop-slop» или «копирайтер».

## Файлы

| Что | Куда | Образец |
|---|---|---|
| Готовый ролик | `video/<ролик>/<Название>.mp4` | — |

| Обложка | `youtube-ai/cover_<ролик>/` | `examples/make_short_cover.py` |

## Описание (структура из `description_boj.txt`)

НАЗВАНИЕ (кто выбрал и когда) → ФАЙЛ РОЛИКА → КАТЕГОРИЯ → ОПИСАНИЕ: название, ссылка-заглушка, 2–4 предложения о сути без воды, обещанное в ролике + ссылка на Telegram `https://t.me/your_channel`, таймкоды глав (из `words_final.json` + пауз), честная строка о том, что сгенерировано ИИ, 2–3 хэштега → ТЕГИ (через запятую, рус + англ, транслит названий: «клод код») → ЗАКРЕПЛЁННЫЙ КОММЕНТАРИЙ (польза + вопрос зрителям) → ЧТО ВЫЛОЖИТЬ В TELEGRAM ДО РОЛИКА → строка про музыку, если лицензия требует автора → ПРОМПТ ДЛЯ ОБЛОЖКИ.

Название предлагай 3–5 вариантами, выбирает автор. Цифры в названии — только проверенные.

## Субтитры

`python $SK\srt.py ..\video\<ролик>\talk\words_final.json "Субтитры - <Название>.srt"` из папки `youtube-ai`. Если в голос вставлены паузы или заставка — времена должны быть во времени ролика: пересчитай `words_final.json` через те же паузы перед запуском. Пополняй `FIX` под ролик (имена, названия), потом прочитай srt глазами.

## Обложка

- Горизонтальная 1280×720. Обычно автор генерирует её в ChatGPT по твоему промпту (английский, «use the attached … exactly», крупный короткий русский текст в кавычках, «readable on a phone, no other text»), с вариантом «с моим лицом» и запасным планом, если логотипы вышли кривыми (пустые круги → наложишь сам через PIL).
- Альтернатива — композиция-обложка в Remotion на 1 кадр.
- Три варианта текста на обложку, 2–4 слова, не повторяют название (`video/mcp/thumbs`, `bot-zashita/thumbs`).

## Пост в Telegram

Эмодзи-заголовок жирным с названием, 1–2 предложения сути, «что меня удивило» 3 пунктами, ссылка на ролик, вопрос в конце. Если в ролике что-то обещано «в Telegram» (шпаргалка, промпты, карточки) — пост с этим обещанием пишется до публикации ролика, напомни автору.

## Реклама в роликах

Партнёрские вставки — только с маркировкой (erid) и договором. Пока erid нет, рекламный блок держи отдельным файлом и не вставляй.
