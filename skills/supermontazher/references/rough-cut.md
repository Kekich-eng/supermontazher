# Черновой монтаж: голос и разговорная часть

Два сценария. Почти все ролики с 07.10 — **без лица** (сценарий А). Говорящая голова (Б) — первые ролики.

## А. Озвучка для ролика без лица (основной путь)

Папка `video/<ролик>/talk/`. Озвучка приходит из OBS (`<папка записей OBS>\<дата>.mp4`) или с телефона.

```powershell
cd "<проект>/video\<ролик>\talk"
ffmpeg -y -i "<запись>" -vn -ac 2 -ar 44100 -c:a pcm_s16le full.wav
ffmpeg -y -i full.wav -ac 1 -ar 16000 audio.wav
$env:PYTHONUTF8 = '1'
python $SK\transcribe.py                 # -> words.json, transcript.txt
```

`$SK` = `${CLAUDE_PLUGIN_ROOT}/skills/supermontazher/scripts`. Скрипты можно не копировать, а запускать по пути: они работают с файлами текущей папки. Копируй `build_voice.py`, потому что в нём правится `REMOVE`.

1. **Прочитай `transcript.txt` целиком.** Найди дубли (обычно оставляют ПОСЛЕДНИЙ дубль), оговорки, «Алиса, стоп», обращения «это надо вырезать», хвост после последней фразы.
2. Спорные места перерасшифруй окнами: `python $SK\win.py 160-170 236-252`. Окно даёт точные таймкоды слов исходника, общая расшифровка ошибается до секунды и склеивает дубли.
3. Впиши интервалы в `REMOVE` (секунды исходника, у каждого комментарий «что это»), запусти `python build_voice.py` → `cut.wav`, `map.json`. Скрипт сам выкидывает вздохи и шорохи (куски без слов) и печатает, что выкинул.
4. `python $SK\voice.py cut.wav voice.wav` → `voice.wav` (−15,5 LUFS) и `final16.wav`.
5. `python $SK\verify.py` → `words_final.json` + список кандидатов с временем исходника. Остатки → в `REMOVE`, повтори 3–5. Обычно два круга.
6. `words_final.json` — источник ВСЕХ времён анимации и субтитров. Перенос в Remotion: `python $SK\words_to_ts.py words_final.json ..\..\free-claude-code\remotion\src\<имя>Words.ts`.

Голос кладётся в общий проект жёсткой ссылкой: `New-Item -ItemType HardLink -Path ...\remotion\public\<имя>\voice.wav -Target voice.wav` (или `ln -f` в bash).

### Вставки в голос
Если в ролик нужно вставить живую реакцию из записи или паузу под зрелищную сцену (бой, геймплей), голос не режь заново. Держи все времена в секундах голоса, а паузы описывай списком: `const V = voiceToVideo([[215.1, 12], [229.9, 16]])` из `kit.tsx`. Так сделаны «Бой» (две паузы под раунды) и «Сравнение» (15 живых реакций со своим звуком, список `INS`).

## Б. Говорящая голова (видео + звук)

Папка `talk/`, скрипт `build_talk.py` (копируй). Он режет по номерам слов `REMOVE` и по времени `EXTRA_CUTS`, привязывает склейки к кадрам и пишет `select.txt` для видео.

```powershell
python build_talk.py
ffmpeg -y -i "<запись>.mp4" -i cut.wav -/filter:v select.txt -map 0:v -map 1:a -c:v h264_nvenc -preset p5 -rc vbr -cq 20 -b:v 0 -pix_fmt yuv420p -c:a aac -b:a 192k -ar 48000 -movflags +faststart rough.mp4
ffmpeg -y -i cut.wav -ac 1 -ar 16000 final16.wav; python $SK\verify.py
```

Голос для говорящей головы обрабатывай тем же `voice.py` (подставь его выход вместо `cut.wav` при рендере). Настройки: `SILENCE_DB` −45 для OBS с шумодавом, −42 для телефона; `PAD` 0.16.
Наезды камеры на склейках: список склеек из `map.json` → на каждой второй масштаб 1.07, скачок выглядит как смена плана (пример `examples/Full_face_screen.tsx`).

## Что вырезать, что оставлять

- Вырезай: паузы, отдельные «вот», «ну», «короче», «э», повторы, фальстарты, кашель, обращения к колонке, оборванные концовки, места, где автор сам говорит «это вырежи».
- Оставляй: «вот это», «вот такие» (там показ), «там» и «в принципе» внутри быстрой речи без проверки окном не трогай.
- Фактические ошибки в речи не вырезаются молча: скажи, что вырезал и почему, предложи вернуть. Если цифра в речи расходится с реальностью («за пять минут», а по записи 8:57), ставь сноску на экране и не выноси цифру в название.
- Граница выреза не должна съедать начало слова (10.10 срезалось «Отключите»). После правки проверь окном 2 с вокруг склейки.
- Если автор присылает таймкоды запинок из готового ролика — переводи их во время исходника через `map.json` (или `verify.py` печатает src) и добавляй в `REMOVE`.
